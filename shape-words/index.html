Download as one shape is a single .stl. Tinkercad welds that into one solid you cannot pull apart — use it when the figure is ready to print. Download separate shapes is a zip with one file per shape, plus HOW-TO-PLACE.txt, so you can move each piece.

    
    
      
  1. Unzip the download. In Tinkercad, click Import and choose 01-….stl first. Units: Millimeters. Scale: 100%.
    2. 
      
  2. Import each next file the same way. Follow HOW-TO-PLACE.txt to move and lift it. Do not click Group yet, or the shapes stick together.
    3. 
      
  3. Tinker. Check the size box is still ≤ 20 cm³.
    4. 
      
  4. When it looks right, select all → Group, then Export → .STL for the Bambu printer.
